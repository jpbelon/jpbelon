About Me

I am a Software Engineer with a strong focus on backend development, API design, and software architecture.

I build structured and maintainable applications using Java and Spring Boot, working with REST APIs, relational databases, authentication, validation, exception handling, automated testing, containerization, and API documentation.

I also work with Python and Apex (Salesforce) and have familiarity with JavaScript, HTML, CSS, and React, giving me a broader understanding of how complete software systems are designed and how backend services integrate with user-facing applications.

My development approach emphasizes clean code, separation of concerns, clear architecture, maintainability, and reliable system design.

Engineering Areas

Backend Development — Java, Spring Boot, RESTful APIs, layered architectures, DTOs, validation, and exception handling.

Data & Persistence — PostgreSQL, SQL, Spring Data JPA, Hibernate, and database migrations.

API Security & Documentation — Spring Security, JWT, OAuth2 Resource Server, OpenAPI, and Swagger UI.

Testing & Development Workflow — JUnit, Spring Boot Test, Testcontainers, Postman, Git, and GitHub.

Infrastructure & Tooling — Docker, Maven, IntelliJ IDEA, and Visual Studio Code.

Additional Technologies — Python, Apex (Salesforce), JavaScript, React, HTML, and CSS.
